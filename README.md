# Speller

Браузерная игра для изучения слов через произношение. Сверху падают предметы,
микрофон слушает постоянно. Назвал предмет вслух на изучаемом языке — сбил,
не успел — раунд окончен, и слово, которое подвело, показывается с озвучкой.

Языка два, и это разные вещи. **Язык интерфейса** — русский или английский,
определяется по браузеру и переключается на стартовом экране. **Язык обучения** —
английский, русский или вьетнамский, выбирается там же: это то, на чём игрок
называет предметы. Конечная цель — приехал в новую страну, учишь местные слова.

Ставится на домашний экран как PWA.

## Как проверялось произношение

Задача не «распознать речь», а закрытый словарь: на экране в любой момент
несколько известных слов, надо понять, названо ли одно из них.

Взят **Web Speech API** — бесплатно и без бэкенда. Главным риском был
многолетний баг iOS, из-за которого Safari не давал распознавание сайтам,
запущенным с иконки домашнего экрана. Проверка на живом устройстве
(iOS 18.7 / Safari 26.6) показала, что **баг больше не воспроизводится**:
распознавание в standalone работает. Полный разбор с журналами —
в [research/PROBE-RESULTS.md](research/PROBE-RESULTS.md).

Диагностика заодно дала измеренные ограничения, которые определяют архитектуру:

- решение принимается по промежуточным результатам (реакция 0.2–0.4 с), а не по
  финальным (те опаздывают на ~2 с и приходят только после паузы в речи);
- в промежуточных результатах ровно одна альтернатива и нулевой confidence;
- короткие слова искажаются систематически (`ball` → «Bowl», `tree` → «free»),
  поэтому фонетическое сравнение обязательно;
- микрофон захватывается один раз за сессию: после освобождения следующий
  захват на Safari приходит мёртвым без всякой ошибки.

## Стек

TypeScript, Vite, без фреймворка. GSAP для движения, `double-metaphone` для
фонетического матчинга английского, Vitest для тестов ядра.

Сравнение услышанного разное для разных языков и описано профилем
(`src/core/matcher.ts`): английский сравнивается фонетически, русский — по
Левенштейну со свёрткой ё/е, вьетнамский — по Левенштейну без тонов, потому что
тоны распознаются менее уверенно, чем сами слоги. Неразличимые после свёртки
слова игра не показывает одновременно, и список таких пар проверяется тестом
на каждом языке.

## Разработка

```bash
npm install
npm run dev -- --host     # игра
npm test                  # тесты ядра: матчер и правила игры
```

Ассеты уже закоммичены, и заново их обычно тянуть не нужно. Если понадобилось:
`npm run assets` — иконки Streamline, `npm run music` — фоновый трек (последнему
нужен **ffmpeg** в PATH: он режет концовку и сводит петлю). Условия обоих
источников — в [ASSETS.md](ASSETS.md).

Стенд дизайн-системы — `/design-system.html`.

Проверка на телефоне требует HTTPS. Локальный дев-сервер выставляется наружу
туннелем:

```bash
cloudflared tunnel --url http://127.0.0.1:5173
```

Быстрый туннель живёт, пока запущен `cloudflared`, и адрес у него каждый раз
новый: после перезапуска ярлык с домашнего экрана телефона ведёт в никуда, и
его надо ставить заново.

Дальше открыть выданный адрес в Safari, добавить на домашний экран и запустить
с иконки — распознавание проверяется именно в этом режиме. Музыка проверяется
там же и только там: в браузере на столе о поведении на телефоне она ничего не
скажет. Протокол — [research/PROBE-CHECKLIST.md](research/PROBE-CHECKLIST.md).
